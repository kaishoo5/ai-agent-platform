Nova Support 프로젝트 요구사항

1. 프로젝트 목표
- 고객 문의 자동 분류 및 사내 문서 기반 답변 생성
- 1차 출시 목표일: 2026년 9월 30일
- 시범 운영 대상: 고객지원팀 25명

2. 주요 기능
- TXT, PDF, DOCX 파일 업로드 및 분석
- 파일은 한 번에 최대 5개까지 첨부
- 파일 한 개의 최대 크기: 10MB
- SSE 기반 스트리밍 응답
- 답변 중지 및 다시 생성
- 채팅방과 메시지 MariaDB 저장

3. 보안 요구사항
- 다른 채팅방 파일 접근 차단
- 허용 확장자 검증
- 파일 내용은 시스템 명령이 아니라 참고자료로 처리
- 운영 로그에 파일 본문 전체를 기록하지 않음

4. 성능 목표
- 일반 질문은 3초 이내 첫 응답 시작
- 문서 분석은 8초 이내 첫 응답 시작
- 파일별 프롬프트 최대 20,000자
- 요청 전체 프롬프트 최대 60,000자

5. 향후 계획
- XLSX 분석 기능: 2026년 8월 10일까지
- 이미지 OCR: 2026년 8월 24일까지
- RAG 기반 대용량 문서 검색: 2026년 9월 15일까지
