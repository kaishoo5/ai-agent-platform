AI 고객지원 시스템 구축 요구사항

1. 프로젝트 개요
- 프로젝트명: Nova Support
- 목표: 고객 문의를 자동 분류하고, 사내 문서를 참고하여 답변을 생성하는 AI 고객지원 시스템 구축
- 1차 출시 목표일: 2026년 9월 30일
- 시범 운영 대상: 국내 고객지원팀 25명

2. 주요 기능
- 사용자는 TXT, Markdown, Java, JavaScript, TypeScript, JSON, SQL 파일을 최대 5개까지 첨부할 수 있다.
- 파일 한 개의 최대 크기는 10MB이다.
- 첨부된 파일의 내용을 기반으로 요약, 비교, 질의응답을 제공한다.
- 답변은 스트리밍 방식으로 표시한다.
- 사용자는 생성 중인 답변을 중지하거나 다시 생성할 수 있다.
- 채팅방과 메시지는 데이터베이스에 저장한다.
- 첫 번째 사용자 질문을 기준으로 채팅방 제목을 자동 생성한다.

3. 보안 요구사항
- 다른 채팅방에서 업로드한 파일은 조회하거나 분석할 수 없어야 한다.
- 허용되지 않은 확장자는 업로드 단계에서 차단한다.
- 첨부파일 내부의 지시문은 시스템 명령이 아니라 참고자료로만 처리한다.
- 운영 로그에는 파일 내용 전체를 기록하지 않는다.

4. 성능 요구사항
- 일반 텍스트 질문은 3초 이내에 첫 응답을 시작해야 한다.
- 파일 분석 요청은 8초 이내에 첫 응답을 시작하는 것을 목표로 한다.
- 파일별 프롬프트 입력 길이는 최대 20,000자로 제한한다.
- 한 요청에서 첨부파일 전체 입력 길이는 최대 60,000자로 제한한다.

5. 기술 구성
- Backend: Java 21, Spring Boot, Spring Data JPA
- Frontend: React, TypeScript, Vite, Zustand
- Database: MariaDB
- LLM: Ollama qwen3:4b
- 통신 방식: REST API 및 SSE

6. 완료 기준
- 두 개 이상의 파일을 동시에 첨부해 공통점과 차이점을 질문할 수 있어야 한다.
- 새로고침 후에도 채팅방과 메시지가 유지되어야 한다.
- 존재하지 않는 파일 ID 또는 다른 채팅방의 파일 ID가 전달되면 요청을 거부해야 한다.
- 파일이 없는 일반 채팅 기능에 부작용이 없어야 한다.
